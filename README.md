# Vida+ 📋

Sistema de gerenciamento de listas desenvolvido em Java para auxiliar o público 60+ na organização de informações importantes do dia a dia.

## 📖 Sobre o Projeto

O **Vida+** é um projeto desenvolvido para a disciplina de **Projeto Integrador** do curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

O sistema foi criado com o objetivo de oferecer uma ferramenta simples e acessível para auxiliar idosos na organização de tarefas, medicamentos, compromissos e outras informações essenciais.

O desenvolvimento ocorreu ao longo de aproximadamente **6 meses**, utilizando os conhecimentos adquiridos durante o primeiro semestre do curso.

O projeto foi desenvolvido utilizando **Java puro**, sem Programação Orientada a Objetos (POO), focando nos conceitos fundamentais de lógica de programação, algoritmos, estruturas de decisão, estruturas de repetição, métodos, manipulação de arquivos e persistência de dados.

---

## ✨ Funcionalidades

### 💊 Lista de Medicamentos

Permite cadastrar, consultar, editar e remover medicamentos.

### 📅 Lista de Compromissos

Permite registrar compromissos importantes e acompanhar a agenda.

### 📞 Lista de Contatos

Permite armazenar e gerenciar contatos importantes.

### 🛒 Lista de Compras

Permite criar e organizar listas de compras.

### 📝 Anotações Gerais

Permite registrar observações, lembretes e informações diversas.

## 📂 Estrutura do Projeto

```text
CRUD-algoritmo/
│
├── src/
│   └── Application/
│       ├── ProgramasListas.java
│       ├── medicamentos.csv
│       ├── anotacoes.csv
│       ├── compromissos.csv
│       ├── contatos.csv
│       └── compras.csv
│
└── README.md
```

Os dados são armazenados localmente em arquivos CSV, permitindo que as informações permaneçam salvas mesmo após o encerramento do programa.
